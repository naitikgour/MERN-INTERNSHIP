## Daily Highlights
- **Day 01**: Environment setup, React 19 SPA architecture, `App.js` with custom message and bonus `Hello.js`.
- **Day 02**: JSX & Components, `Header`, `Footer`, `Greeting` with props, and `ProfileCard` list mapping.
- **Day 03**: `useState` Hook: Counter App and User Registration Form with live real-time preview.
- **Day 04**: `useEffect` Hook: Data fetching from JSONPlaceholder (`/users` and `/posts`) with loading & error handling.
- **Day 05**: Event handling (`onSubmit`, `onChange`) and conditional rendering for user login state.
- **Day 06–07**: Personal Blog UI mini project with search filtering, toggle post details, modular cards, and clean styling.
