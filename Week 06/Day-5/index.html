Data Validation & Relationships

Mongoose schema validators, custom regex, ObjectId referencing, and .populate()

Option 1: Embedding (Subdocuments)

addresses: [...]

Store nested data inside the parent document. Best for fast 1-to-few reads (e.g. user delivery addresses).

{
  name: "Rahul",
  addresses: [{ street: "MG Road", city: "Delhi", pin: 110001 }]
}

Option 2: Referencing (Best Practice)

ref: "User"

Store separate collections linked by ObjectId. Use .populate("user") to join without data duplication.

{
  productName: "Laptop",
  amount: 45000,
  user: ObjectId("65fa9d01") // Normalized Link
}
