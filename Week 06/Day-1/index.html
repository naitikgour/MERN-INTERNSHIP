SQL vs NoSQL

SQL (Relational): Table-based with strict schema, rows & columns (MySQL, PostgreSQL, Oracle). Uses SQL queries.
NoSQL (Document-based): Flexible schema, stores JSON/BSON documents in collections (MongoDB, Firebase). High scalability and performance.

JSON vs BSON

JSON (JavaScript Object Notation): Human-readable text format used in APIs and client-server communication.
BSON (Binary JSON): Binary-encoded serialization format used internally by MongoDB for fast traversals, indexing, and rich datatypes (ObjectId, Date, Binary).
