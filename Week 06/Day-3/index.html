Mongoose Models & Schemas

Schema definition, built-in validation, custom logger middleware, and REST CRUD API

Schema Definition 

const studentSchema = new mongoose.Schema({
  name: { type: String, required: true },
  age: { type: Number, required: true, min: 5, max: 80 },
  department: { type: String, default: "General" },
  createdAt: { type: Date, default: Date.now }
});

Active Validations

  • required: name, age
  • min: 5: enforces minimum age
  • max: 80: enforces maximum age
  • default: "General" if department omitted
