Authentication & Authorization

Cookies vs Sessions vs Tokens, JSON Web Token (JWT) Anatomy, and Tampering Detection

Authentication

"Who are you?" Verifying user identity before granting system access.

• Password & Email verification
• Multi-Factor Authentication (OTP, SMS)
• Social logins (Google, GitHub OAuth)

Authorization

"What can you do?" Granting or denying access to specific resources based on role.

• Admin can access /admin panel & delete users
• Regular users can only edit their own profile
• Role-based access control (RBAC)
