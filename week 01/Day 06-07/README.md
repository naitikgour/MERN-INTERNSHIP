# Naitik Gour — Portfolio Website

A responsive, minimalist portfolio made with separate HTML, CSS, and vanilla JavaScript files.

## Files
- `index.html` — page content and sections
- `style.css` — layout, styling, responsiveness, and dark theme colors
- `script.js` — mobile menu, typing effect, theme toggle, and contact form demo
- `assets/` — illustrations cropped from the supplied portfolio design image

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.
3. Internet access is needed for Google Fonts and Iconify icons.

## Personalize before publishing
- Update the GitHub, LinkedIn, Telegram, and X links in `index.html`.
- Replace `hello@naitikgour.dev` with your real email address.
- Replace the project links with your GitHub repositories or live demos.
- The contact form currently opens the visitor's email app using `mailto:`. Connect Formspree, EmailJS, or your own backend if you want messages submitted directly from the page.
- Project descriptions are starter copy; adjust them to match what your projects actually do.

## Technologies
HTML5, CSS3, vanilla JavaScript, Google Fonts (DM Sans + Manrope), Iconify.
