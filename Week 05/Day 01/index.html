Task 2 File System Module (fs.writeFile & fs.readFile)

Asynchronously writes to student.txt then reads the content back.

const fs = require("fs");
fs.writeFile("student.txt", "Welcome to Node.js!", (err) => {
  if (err) throw err;
  fs.readFile("student.txt", "utf8", (err, data) => {
    console.log("File content:", data);
  });
});
Task 3 System Information Logger (system-info.js)

Inspects host machine resources using the built-in os module.

const os = require("os");
console.log("Operating System:", os.platform());
console.log("Architecture:", os.arch());
console.log("Total Memory:", os.totalmem());
console.log("Free Memory:", os.freemem());
console.log("CPU Info:", os.cpus());
